## Technologies

### TypeScript

TypeScript is the language of choice for this project. It makes the developer experience so much better and reduces bugs very effectively.

### Vite

Vite is the bundler I decided to go with as it is fast, powerful and provides a great developer experience.

### Prettier

Prettier i used for formatting together with [prettier-plugin-organize-imports](https://www.npmjs.com/package/prettier-plugin-organize-imports) to make code formatting universal across computers and contributors.c

### Sass

I have always enjoyed using Sass mostly because of it's nesting functionality. It makes organising and using stylesheets much more enjoyable. I look forward to [when this is implemented in the official CSS standard.](https://drafts.csswg.org/css-nesting-1/)
